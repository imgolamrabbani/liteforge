LiteForge Documentation

Zero-dependency WebAssembly SQLite studio for VS Code, Remote-SSH, WSL, and Cursor.

1. Quickstart

  1. Install LiteForge (caliberhttp.liteforge) from the VS Code Marketplace, Open VSX, or download the signed .vsix directly from GitHub Releases (v1.1.0).
  2. Click any .db, .sqlite, or .sqlite3 file in the VS Code Explorer to open it in LiteForge Studio.
  3. Browse paginated tables, inspect NULL/BLOB/JSON cells, switch to the SQL Runner tab, or run LiteForge: Import CSV / JSON into SQLite Table to import datasets with automatic type inference.

2. Pro Features

  • Transactional Inline Editor: Double-click any cell to stage updates, preview the BEGIN/COMMIT SQL diff, and write back atomically.
  • Visual Schema & FK ERD: Inspect tables, columns, primary keys, foreign keys, and indexes visually.
  • 2-File DB Diff: Compare two .sqlite files and generate deterministic migration SQL.
  • Full .sql Dump: Export schema + data (including X'...' BLOB literals) or a multi-table JSON bundle.

3. Polar.sh License Activation

Purchase a Pro license via Polar.sh ($19 Early Bird Perpetual or $5/mo Monthly), then run LiteForge: Activate Pro License and paste your LITEFORGE-... key. Keys are stored in VS Code SecretStorage with 72-hour silent re-validation and a 14-day offline grace window.
